# The pages

Design work for Pond Hopping that was published as a Claude artifact and
argued over before anything was built. Saved here as it was written, newest
first, because the reasoning is worth more than the pictures and both were
living on somebody else's server.

Each file opens on its own in a browser. Web fonts still come from Google, so
they want a connection to look exactly right. The comment at the top of each
one carries its original URL and the date it went up.
